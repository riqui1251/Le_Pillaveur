# Règles du Menteur (dés)

Le jeu d'enchères et de bluff au gobelet — l'esprit du Perudo, jouable **gratuitement en ligne de 2 à 6 joueurs**.

## Le principe

Chaque joueur secoue ses dés **cachés sous son gobelet** : lui seul les voit. À tour de rôle, on enchérit sur ce que contient la table ENTIÈRE (« il y a au moins quatre 3 »). Vous n'y croyez pas ? Criez **« MENTEUR ! »**.

## Déroulement

1. **Le lancer** : chacun regarde ses dés en secret.
2. **Les enchères** : chaque joueur doit surenchérir (plus de dés, ou une valeur plus haute) — ou accuser le précédent.
3. **MENTEUR !** : tous les gobelets se lèvent. Si l'enchère était tenue, l'accusateur perd un dé ; sinon, c'est le menteur qui trinque.
4. Le joueur qui n'a plus de dés est éliminé.

## Variantes incluses

- **Palifico** : quand un joueur passe à un seul dé, la manche se joue à valeur fixe.
- **Calza** : pariez que l'enchère en cours est EXACTEMENT juste pour regagner un dé.

## Victoire

Le dernier joueur avec des dés remporte la table.

## Astuces

- Vos propres dés sont votre seule certitude : enchérissez autour de ce que vous tenez.
- Les statistiques aident : sur 20 dés, chaque valeur sort en moyenne un peu plus de 3 fois (les As comptent souvent double, selon la manche).

## Le mode apéro

Perdre un dé se fête d'une gorgée ; l'élimination, d'une tournée symbolique. Mode soft : les dés seulement.
